# Somewhere Wild (shipped, map-screen contour + marker + card)
**Why:** The Bloom colour gradient (home-range) is unreadable at a glance even after fill alpha went 0.28 -> 0.6; vision cannot read absolute values from a gradient over varying tiles. Fix is a legible shape (second contour, marker) plus one sentence of text, restating the same fact, never a new number. One change, not split: the contour/marker mean nothing without the card, the card's tap-to-pan needs the marker.
**Decisions:**
- Hard dependency on home-range-rewards (`BALANCE.freshGround.k`, `BALANCE.freshGround.displayThresholdMultiplier` in `src/economy/balanceConfig.ts`): a wild contour is only honest if wild ground actually pays more.
- Wild threshold is derived, never a bare 0.75: `WILD_THRESHOLD = clamp(ceil to 0.05 of (WILD_MARGIN * (displayThresholdMultiplier - 1) / k), 0.60, 0.95)`, `WILD_MARGIN = 1.8` (bonus at threshold must be 1.8x the bonus at the display floor). At k=0.6 gives exactly 0.75 (multiplier 1.45, ~6.5 days stale). Clamp: at k=0.3 raw math wants 1.5 (impossible), at k=1.0 wants 0.45 (card would fire constantly). Earlier version without the margin gave 0.45 (an arithmetic error); game-economist validated the fix. Keep the code comment pointing at `k` so a retune re-derives.
- Second contour: second pass of `hrMarchingSquaresSegments` over `wildBlurred` in `src/web/homeRangeRendererScript.ts`; warm accent `#F39C12`, thinner, dashed; no new bridge payload or colour token.
- Cluster selection (RN side, `src/utils/wildSpot.ts`): cells >= threshold, 8-neighbour components, drop components under `CELLS_PER_STREET` (11, exported from `grid.ts`), score by sum of `visits` (not wildness, which is flat 1.0 past the 18-day ceiling), tie-break cell count then lowest `(ix, iy)`; anchor = highest-`visits` cell (ties lowest `(ix, iy)`), not a centroid.
- One marker only, sent via bridge message `SHOW_WILD_SPOT` (lat/lon), next to `SHOW_HOME_RANGE`.
- Card on the map screen only (never Den, never push, no count/badge/dismiss, no empty state). Priority: (1) New Ground event within 48h, (2) wild cluster, else renders nothing (the majority of the time). Evaluated on foreground, debounced (~15-30 min or when Range cell count changed) to avoid a reverse-geocode call per app switch.
- New Ground event is a persisted single overwritten row in `HomeRangeRepository` (`getLastNewGroundEvent` / `recordNewGroundEvent(occurredAt, cellIds)`), written at Finish Walk when new cells clear `NEW_GROUND_MIN_CELLS`. 48h expiry evaluated on read, no cleanup job. Reason: the Range does not remember when a cell joined. "N new streets" = `max(1, floor(newGroundCellCount / CELLS_PER_STREET))`.
- Label via `expo-location.reverseGeocodeAsync` (no new dependency), cached per anchor cell id / event `occurredAt`. Fallback: bounded scan of up to 20 most recent tracked walks whose bbox overlaps the cluster, reverse-geocode one of their real fixes. Wild state needs a place name; if unresolved, neither marker nor card renders (no orphan marker). New Ground state renders without a place name.
- Copy (subject is the place or the dog, never "you"): New Ground `{dog} learned {n} new street{s} [by {place}] {today|yesterday|on Weekday}.` Wild: 4 rotating variants, since 2026-10-18 on a sniff-and-mark theme instead of overgrown grass (owner: "Gras mähen passt nicht"): A scent mark faded, B neighbour dogs marked, C fresh sniff-mail, D go sniffing and marking again, `index = hash(anchorCellId + variantEpoch) % 4`, epoch advances only when the winning cluster changes.
- Known risk: OS geocoder unreliable on some Android devices, so the card may never appear there (acceptable silent degradation; verify on more than one device). A player away 3+ weeks surfaces their most-walked spot as the wild spot (intended).
**Rejected:**
- Hardcoded `WILD_THRESHOLD = 0.75`, because a lower `k` silently drops it below the display floor (k=0.3 -> multiplier 1.225), circling ground with no Fresh Ground beat.
- "Street of the walk that first painted the cluster" fallback, because `Cell` has no per-cell provenance and a schema change for a rare path is not worth it.
- Marker-only when label fails, because an unexplained marker is exactly the clutter the card rule avoids.
- Colour/opacity tuning, because the problem is that gradients carry no legible thresholds.

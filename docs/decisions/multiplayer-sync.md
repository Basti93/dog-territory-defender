# Multiplayer household sync + neighbour dogs (2026-10-18, M1-M4 shipped, M5+ open)
**Why:** Everything was local to one phone. Owner and partner share one dog (Android + iPhone): one Buddy, one Home Range, one Den. Smallest real multiplayer; forces accounts, sync, conflicts, hosting, privacy to be solved for 2 trusted users before strangers. Social layer (other real players, leaderboards) NOT built.
**Decisions:**
- Model: household (1 dog, 1..4 players, `HOUSEHOLD_MAX_PLAYERS`, tested with 2); each phone = device with own bearer token. Household creation = operator CLI over ssh only; no admin endpoint/token on HTTP.
- Stack: `server/` (own package.json, no workspace): Node 22, Fastify 5, TypeBox, Drizzle + Postgres 16, vitest. Fastify over Hono (Node-first, built-in validation); Drizzle over Prisma (no Rust engine, api budget 384 MiB); Postgres over SQLite for cloud parity + `SELECT ... FOR UPDATE` on `den_state`.
- Shared code: contract `src/sync/apiContract.ts` imported by server by relative path; server also imports pure economy/grid files (allowlist in `server/README.md`, purity test `src/sync/__tests__/sharedPurity.test.ts` fails on RN/expo/i18n imports). Same numbers, one definition.
- Authority: walks append-only (client UUID, soft delete, cells never un-painted); cells derived on server; territories server-authoritative; Den state (treats, XP, level, buildings, manual-log counters) server-authoritative via idempotent commands (`clientId` in `command_log`; `walk.finish`, `walk.manualLog`, `den.upgrade`, `walk.delete`, `dog.update`, `player.rename` 1-24 chars, `gift.open`). Dog name last-writer-wins. Settings/stats/achievements stay per device.
- Reward: server recomputes; local estimate shown instantly, server number wins quietly; rejected upgrade (`insufficient-treats`) rolls back with a gentle line.
- Cells: server keeps `cell_days(household,ix,iy,day)`; `visits = baseline_visits + count(days)` (household timezone). Union of days is commutative/idempotent and keeps the once-per-cell-per-day cap household-wide. Client applies `max` per field via `HomeRangeRepository.mergeCells`.
- Anti-snowball: Beginner's Luck keyed to household creation date; manual-log quota (2/day, 1 route refresh/day) household-wide; no "more members" bonus.
- Feed: one append-only `events` table (seq cursor) = change feed + Doorstep feed. `GET /v1/events?after&wait<=25s` long-poll (RN has no EventSource), `GET /v1/snapshot` to bootstrap. Time: `serverTime`, `clockOffsetMs`; walks >5 min future or >30 days old rejected.
- Client (`src/sync/`): SQLite `sync_outbox`, foreground-only sync, backoff 5 s to 5 min, 15 s fetch timeout, no background tasks/NetInfo (native deps). Token unencrypted at rest (accepted; `expo-secure-store` before public release), never in Backup JSON. Restore disabled while joined.
- Auth: single-use invite (8 chars, 24 h, hashed), `POST /v1/join`; token 32 random bytes, SHA-256 stored; swappable `Authenticator` seam for later OIDC.
- Hosting: home server, compose project `dog-territory` (api 384m, db 512m, tailscale sidecar 128m = 1 GiB), 127.0.0.1:7000/7001. Public via Tailscale Funnel on own sidecar node `your-server.example.com:443` (owner decision: no Tailscale on phones). Backups: daily 06:30 pg_dump, 14 days (never 02:00-06:00).
- Hardening (Decision 16): only `GET /healthz` + `POST /v1/join` unauthenticated, everything else 401 incl. unknown paths; join 5/min and 20/day per IP, global 100/h; 120 req/min per token; 30/min unauth per IP; `banned_ips` (10 fails/10 min = 1 h, doubling to 24 h); bodyLimit 64 KiB; JSON only; helmet, no CORS; 200 commands + 50 walks/day per household; logs never hold tokens/coordinates; IP logs ~14 days; kill switch `docker compose stop api` (app is offline-first).
- Privacy: members see each other's full routes (consent tap, `players.consented_at`); anything cross-household needs 100 m start fuzz; `DELETE /v1/me`, `DELETE /v1/household`. Needs privacy policy, DPIA, legal check before any non-test user.
- Track B "Nachbarhunde" (bots, `NEIGHBOURS_ENABLED`, default true in `deploy/docker-compose.yml`, enable only when both phones have the build): six bot households (`is_bot`; Momo, Pfote, Bruno, Keks, Lotte, Nebel) created at host's first tracked walk; routes generated from OSM ways (Overpass, ~2 km tiles cached in `street_tiles`, loops within +-20 % of target, home block `HOME_BLOCK_RADIUS_M` 150 m excluded; fallback = offset copies of host's last 10 walks 300-1500 m). Never go through `walk.finish`; no territories, no Den. Tunables in `src/economy/neighbourConfig.ts`, archetypes in `server/src/neighbours/archetypes.ts`.
- Bot rules: max 2 events/day, 1 gift/day, 1 invitation/ISO week, 3 reactions/week, no `line_key` repeat in 10 days; escalation W1 Momo+Pfote, W2 Bruno, W3 Keks+Lotte+first Viertel-Runde, W4 Nebel. Gift sprinkle `SPRINKLE_FRACTION` 5 % of avg treats over last 14 human walks, credited on `gift.open`, outside the +30 % power budget. Viertel-Runde goal G = B + P (P 4-12 km, B <= 60 % of G, effectively ~10-30 km), no loss state, carry-over up to 50 % of next P, reward yard decoration. Bots are openly "simuliert" (paw-robot badge on the card only).
- Presence (M4): ephemeral `walk_presence` table + `POST/GET /v1/presence` (not in `events`); beat ~30 s, 1 req/10 s per device, <=400 points, purged after 6 h, viewer long-poll foreground only, stale after 3 min. Live share is opt-in (default off, `liveShareEnabled`). Late mini-homecoming: one per app open, partner walk <48 h.
- Ops: `API_LEVEL = 2` (`X-Api-Level`, 426 on writes below `MIN_CLIENT_API_LEVEL`), additive-only changes, unknown event kinds ignored; `deploy/restore-drill.sh`, `BACKUP_COPY_DIR`/`BACKUP_RSYNC_TARGET`.
**Rejected:** client LWW for all (wrong for spendable balance, territories fork); CRDTs (overkill); SSE/WebSockets (no RN EventSource, background kills sockets); Prisma, SQLite-on-server, npm workspaces; OSRM/Valhalla (multi-GB extract on a 7.1 GiB shared host); Tailscale on phones (superseded by Funnel); admin token over HTTP; fail2ban (no OS changes); per-screen refetching of neighbour data; persisting the presence buffer (walk dies with the process anyway); push (iPhone free team has no APNs).
